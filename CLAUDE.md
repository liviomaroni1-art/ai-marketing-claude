# AI Marketing Claude - Project Instructions

## Website & Design Workflow

Whenever the user mentions **website building**, **landing pages**, **web design**, **UI/UX**, **prototyping**, **frontend**, **page layout**, or anything related to building/designing web experiences:

### Skill Sets to Use (ALL namespaces)

1. **`skills/design-*`** (89 skills) — UX strategy, UI design, interaction design, design systems, prototyping, design ops, user research, wireframes, user flows, heuristic evaluation
2. **`skills/uiux-*`** (9 modules) — UI/UX Pro Max: banner design, brand guidelines, design system tokens, slides, ui-styling (Tailwind/shadcn), 15+ stack CSVs (React, Next.js, Vue, Svelte, Flutter), typography, color palettes, Google Fonts
3. **`skills/anthropic-*`** (6 skills) — frontend-design, brand-guidelines, canvas-design, web-artifacts-builder, theme-factory (10 themes), skill-creator
4. **`skills/shadcn-*`** (59 components) — Accordion, Button, Dialog, Table, Sidebar, Carousel, Data Table, Calendar, and all shadcn/ui v4 component docs
5. **`skills/vercel-*`** — Web design guidelines audit (accessibility, focus, forms, animation, typography, performance, dark mode, i18n, hydration)
6. **`skills/web-accessibility-*`** — Principles of web accessibility
7. **`skills/cookbook-*`** (57 skills) — API patterns, tool use, structured output, vision, agent workflows, extended thinking, RAG, agent SDK
8. **`skills/market-*`** (14 skills) — Marketing copy, SEO, ads, email campaigns, landing pages, funnels, brand strategy, competitor analysis
9. **`skills/awesome-*`** (20 skills) — Content research, lead research, competitive ads, domain brainstormer, changelog, document generation (docx/xlsx/pptx/pdf)
10. **`skills/composio-skills/`** (832 automations) — Slack, GitHub, HubSpot, Salesforce, Stripe, Notion, Mailchimp, Shopify, and 800+ more integrations

### MCP Integrations
- **Figma** — read designs, extract design context, generate diagrams, manage Code Connect
- **Canva** — generate designs, search/edit designs, export assets, apply brand kits
- **Vercel** — deploy sites, check deployments, read build/runtime logs
- **Gamma** — create AI-powered presentations, documents, and webpages
- **Notion** — create/update pages, databases, comments
- **Gmail** — draft emails, search messages, read threads
- **Google Calendar** — create/manage events, find free time
- **Calendly** — manage event types, scheduling links, meetings
- **MailerLite** — email campaigns, automations, subscribers, forms

### Design Principles (Always Apply)
- Color systems, typography scales, spacing systems, responsive design
- Accessibility audits (WCAG AA/AAA), semantic HTML, ARIA patterns
- Component specs, design tokens, visual hierarchy
- User personas, journey maps, empathy maps
- Wireframes, prototypes, user flow diagrams
- Performance optimization, lazy loading, SSR/hydration safety

### Workflow
- **Combine marketing + design skills** for landing pages, funnels, and campaign assets
- Use `market-*` skills for copy/strategy and `design-*` + `uiux-*` for visual/UX decisions
- Reference `shadcn-*` docs when building React/Next.js component UIs
- Run `vercel-*` audit on all UI code before shipping
