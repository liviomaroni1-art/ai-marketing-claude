# AI Marketing Claude - Project Instructions

## Website & Design Workflow

Whenever the user mentions **website building**, **landing pages**, **web design**, **UI/UX**, **prototyping**, **frontend**, **page layout**, or anything related to building/designing web experiences:

1. **Use designer skills** (`skills/design-*`) for UX strategy, UI design, interaction design, design systems, prototyping, and design ops guidance.
2. **Use cookbook skills** (`skills/cookbook-*`) for API patterns, tool use, structured output, vision, and agent workflows.
3. **Leverage MCP integrations** when available:
   - **Figma** — read designs, extract design context, generate diagrams, manage Code Connect
   - **Canva** — generate designs, search/edit designs, export assets, apply brand kits
   - **Vercel** — deploy sites, check deployments, read build/runtime logs
   - **Gamma** — create AI-powered presentations, documents, and webpages
4. **Apply the full skill set** proactively: color systems, typography, spacing, responsive design, accessibility audits, component specs, wireframes, user flows, and visual hierarchy.
5. **Combine marketing + design skills** for landing pages, funnels, and campaign assets — use `market-*` skills for copy/strategy and `design-*` skills for visual/UX decisions.
